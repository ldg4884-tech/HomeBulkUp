# 홈벌크업 (Home Bulk Up) v1.4.0

덤벨과 문틀 철봉으로 집에서 근육량을 늘리는 Android 운동 기록 앱입니다. Android 8.0(API 26) 이상을 지원합니다.

## v1.4.0 추가 기능

- **운동 집중 모드**: 현재 운동과 한 세트만 크게 보여 줍니다. 완료 시 다음 세트로 이동하며, 건너뛰기/이전 이동/중단 후 이어하기를 지원합니다. 실제 완료 수와 별도로 진행 위치를 저장합니다.
- **휴식 종료 알림·진동**: AlarmManager로 앱 화면 밖에서도 알림을 예약합니다. Android 13 이상은 알림 권한이 필요하고, Android 12 이상에서 정확한 알람 권한이 없으면 지연될 수 있습니다. 앱 설정에서 알림을 켜고 시스템 채널의 소리·진동을 확인하세요.
- **RIR·세트 종류**: 준비/본 세트와 여유 반복 횟수(RIR 0–5+)를 기록합니다. 준비 세트는 증량·운동량·최고 기록 계산에서 제외하고 별도 집계합니다. 본 세트 RIR이 0–1이면 증량을 권하지 않습니다. 이전 기록은 본 세트·RIR 미기록으로 호환됩니다.
- **과거 기록 편집**: 기록 화면에서 날짜·종목 검색, 무게/횟수/종류/RIR/완료 상태 수정, 세트 삭제, 운동 완료 취소를 지원합니다. 수정·삭제 직후 표시되는 실행 취소는 해당 기록만 되돌립니다.
- **회복 주간**: 시작 날짜부터 7일 동안 휴식 또는 가벼운 운동을 적용합니다. 가벼운 주간은 세트 수 절반(올림), 이전 무게 약 80%를 장비 간격에 맞춰 제안합니다. 원래 루틴을 수정하지 않으며 기간이 끝나면 원래 계획을 표시합니다.
- **운동 일정**: 네 루틴의 요일과 공통 알림 시간을 지정합니다. 홈의 오늘 일정과 운동 요일에도 반영되며 알림은 기기 현지 시간 기준입니다. 재부팅·시간대 변경 시 다시 예약합니다. 휴식 주간에는 운동 알림을 보내지 않습니다.
- **컨디션 메모**: 날짜별 수면·컨디션·불편한 부위·메모를 저장하고 과거 기록에서 확인합니다. 낮은 컨디션·짧은 수면·통증 기록이 있으면 증량보다 회복을 우선하는 안내를 제공합니다.
- **백업 복원 미리보기**: 수동 파일과 내부 백업 모두 날짜·운동 완료·세트·체중·식단·컨디션 기록 수를 검증한 뒤 표시합니다. 확인한 데이터 그대로 복원하며 원본 파일이 바뀌어도 다른 내용을 적용하지 않습니다.

알림 권한 거절, 방해 금지, 제조사 절전, 앱 강제 종료 등은 알림을 제한할 수 있습니다. 앱의 타이머·기록은 권한 없이도 동작합니다. 실제 기기에서 권한과 백그라운드 동작을 확인하세요.

## 기존 기능

- **지난 운동 기록**: 같은 종목의 이전 날짜 무게·횟수를 표시하고, 비어 있는 세트에 불러옵니다. 루틴 순서가 바뀌어도 고유 ID로 오늘의 입력을 유지합니다.
- **다음 목표**: 이전 운동의 모든 목표 세트를 완료하고 상한 반복 횟수를 달성했을 때만 덤벨 증량을 제안합니다. 실패·일부 세트·완료 미확인 기록은 자동 증량에 쓰지 않습니다. 사용자가 수락하지 않은 추천은 기록을 변경하지 않습니다.
- **장비 한계 대응**: 덤벨 최대 무게와 조절 간격을 설정합니다. 증량할 수 없으면 반복 1–2회, 내리는 동작 3초, 또는 1세트 추가 중 하나를 제안합니다.
- **진행 상태 복구**: 세트 입력과 완료 상태, 선택한 운동일·탭, 휴식 타이머의 종료 시각을 저장합니다. 타이머 창을 닫아도 시간은 흐르고, 앱을 다시 열면 경과 시간을 반영합니다. 알림 권한이 있으면 휴식 종료를 시스템 알림과 진동으로 안내합니다.
- **장비별 대체 운동**: 설정에서 덤벨·철봉 보유 여부를 선택합니다. 같은 움직임 중 가능한 종목으로 사용자가 교체할 수 있습니다. 지원 종목이 없는 경우 이를 표시합니다.
- **주간 성장 리포트**: 최근 7일/이전 7일 운동 횟수·완료 세트·운동량(kg×횟수), 과거 대비 최고 무게 갱신을 표시합니다. 0kg 맨몸 운동은 세트 수에는 포함하고 중량 운동량에는 더하지 않습니다. 덤벨 무게는 한 개 기준입니다.
- **체중 평균·정체 안내**: 최근/이전 7일 평균을 비교합니다. 각 구간에 서로 다른 날짜 기록이 최소 3개 있어야 정체를 판단하며, 증가가 0.1kg 미만이면 식단·측정 조건 확인 안내를 표시합니다.
- **자동 백업·복원**: 기록 변경 후 및 하루 한 번 Android WorkManager로 백업합니다. 기기 내부는 날짜별 최근 7개, 사용자가 연결한 문서 폴더는 최근 7개 파일을 보관합니다. 복원 전 보호 사본 3개를 별도로 보관하고, 손상·형식 오류가 있는 백업은 현재 데이터에 적용하지 않습니다. 기존 v1 JSON 백업도 지원합니다.

설정의 **자동 백업 폴더 선택**에서 외부 저장소 또는 Android 파일 선택기가 지원하는 클라우드 공급자를 연결할 수 있습니다. 계정 연결이나 파일 공급자의 클라우드 동기화는 해당 공급자가 관리합니다. 내부 백업은 앱 삭제·기기 분실을 보호하지 않습니다. 절전·강제 종료 상태에서는 예약 실행이 지연될 수 있으며, 마지막 성공 시각과 오류를 설정에서 확인할 수 있습니다.

기존 루틴·체중·식단·사진 인식·수동 백업 기능도 유지합니다. 사진 인식은 음식명/분량을 확정하지 않으므로 사용자가 직접 확인해야 합니다.

## 이전 버전 기록

이전 세트 기록은 날짜와 루틴 위치만 저장했습니다. 업데이트 시 현재 루틴 위치에 맞춰 한 번 이전하며 원본 `exercise_logs`도 보존합니다. 과거에 루틴 순서를 바꿨다면 당시 종목을 복원할 정보가 없으므로 이전 표시를 확인하세요. 과거 기록은 완료 미확인으로 처리해 통계·자동 증량에 사용하지 않습니다. 이후 입력부터는 고유 종목 ID와 당시 종목명을 함께 저장합니다.

## 개발과 검증

JDK 17, Gradle 8.9, Android SDK `platforms;android-35`, `build-tools;35.0.0`, `build-tools;34.0.0`, `platform-tools`가 필요합니다.

```bash
gradle --no-daemon --max-workers=4 testDebugUnitTest lintDebug assembleDebug
```

APK: `app/build/outputs/apk/debug/app-debug.apk`
테스트: `app/build/reports/tests/testDebugUnitTest/index.html`
Lint: `app/build/reports/lint-results-debug.html`

단위 테스트는 추천 경계값·장비 필터·시간 복구·주간 통계·백업 형식 검증을 검사합니다. Compose UI 테스트는 세트 입력·RIR 선택·집중 모드 이동·위치 복구·기록 삭제 취소를 검사합니다. 알림 테스트는 예약·취소·권한 대체 경로·중복 방지·재부팅 복구를 검사합니다. Robolectric 테스트는 실제 Android SharedPreferences, 기록 이전, 루틴 재정렬 후 복구, 보호 사본, 백업 Worker의 성공/폴더 접근 실패를 검사합니다. 실제 기기에서 문서 공급자의 권한 유지·백그라운드 예약·화면 크기·프로세스 재생성도 확인하세요.

CI는 체크인된 `app/src`를 직접 빌드합니다. `HomeBulkUp_Project.zip`은 과거 원본 자료로 남겨 두며 빌드 시 추출하거나 소스를 덮어쓰지 않습니다. 코드를 변경할 때 이 ZIP 또는 온보딩의 별도 작업 복사본을 수정하지 마세요.
