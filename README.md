# 홈벌크업 (Home Bulk Up) v1.2.0

덤벨과 문틀 철봉으로 집에서 근육량을 늘리는 개인 운동 기록 앱입니다.

## 기능
- 주간 운동 루틴과 운동 완료 체크
- 체중·목표 체중 및 변화 기록
- 세트별 운동 무게/반복 기록
- 단백질·칼로리 목표
- JSON 백업 및 복원

## 빌드
GitHub Actions의 **Build Home Bulk Up APK** 워크플로가 Android debug APK를 빌드하고 `home-bulk-up-debug-apk` 아티팩트로 업로드합니다.

앱 소스는 Android Studio/Gradle 프로젝트 구조로 저장해야 합니다.
